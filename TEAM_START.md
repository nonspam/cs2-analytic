# CS2 Analytics — общий запуск для пацанов

### Один человек запускает сервер
Двойной клик:

`START_SHARED_SERVER.bat`

В окне появится адрес вроде:

`http://192.168.1.25:8000/`

### Остальные
Открывают этот адрес в браузере на своих ПК в той же сети.

### Что теперь происходит
- база общая для всех;
- новая игра сохраняется в `shared_state.json`;
- изменения появляются у остальных открытых пользователей автоматически;
- сервер хранит историю изменений;
- закрывать окно сервера нельзя, пока сайт нужен команде.

### Если Windows спросит про Firewall
Разрешить Python для **частной сети**.

### Важно
Это режим для одной локальной сети. Для публичного сайта в интернете нужен отдельный хостинг/VPS и серверная авторизация.
